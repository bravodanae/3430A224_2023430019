# Arbol Binario de Busqueda 

## Descripcion
Este programa implementa un Arbol Binario de Busqueda en C++
Permite insertar, eliminar, modificar y buscar numeros enteros en un arbol, ademas de mostrar los recorridos en preorden, inorden y posorden.  
Tambien se puede generar una visualizacion del arbol usando Graphviz.

## Funcionalidades
- Insertar numeros sin duplicados
- Eliminar numeros (considerando nodos sin hijos, con un hijo o con dos hijos)
- Modificar un numero existente
- Buscar un numero
- Mostrar recorridos:
  - Preorden
  - Inorden
  - Posorden
- Visualizar arbol con Graphviz generando arbol.txt y arbol.png
