# Laboratorio 8 - Metodos de Ordenamiento Interno (Version con Menu Interactivo)

Este programa implementa los metodos de ordenamiento interno y permite al usuario interactuar mediante un menu sencillo.

## Caracteristicas
- Permite al usuario:
  - Ingresar cantidad de elementos
  - Elegir si mostrar o no los vectores
  - Ejecutar los ordenamientos
  - Salir del programa de manera segura

## Metodos implementados
- Burbuja  
- Insercion  
- Seleccion  
- Shellsort  
- Quicksort  

## Compilacion
```
g++ -std=c++17 -O2 laboratorio8.cpp -o laboratorio8
```

## Ejecucion
```
./laboratorio8
```

## Funcionamiento del menu

El programa muestra:

1) Ingresar cantidad de elementos  
2) Elegir si mostrar vectores  
3) Ejecutar ordenamientos  
4) Salir del programa  

El usuario puede ejecutar los metodos cuando quiera y cerrar el programa desde el menu.
