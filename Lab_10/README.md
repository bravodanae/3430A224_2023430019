
# Laboratorio 10 - AYED (Automatizacion)

Contenido:
- laboratorio10.sh : script que automatiza la extraccion y conteo de residuos (LYS, ARG, HIS, GLU, ASP) en los PDBs.
- Obtencion Aminoacidos/ : carpeta generada con archivos filtrados y CSVs:
  - resumen_residuos.csv
  - HEM_residuos.csv, GFP_residuos.csv, ACE2_residuos.csv
  - archivos *_-LYS.pdb, *_-ARG.pdb, ...
Instrucciones:
1. Ejecutar `./laboratorio10.sh` desde la carpeta `Lab_10`.
2. Revisar resultados en `Obtencion Aminoacidos/`.
