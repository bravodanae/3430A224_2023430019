
# arbol AVL de terminos GO

#descripcion
este programa crea y manipula un arbol balanceado AVL de terminos Go , el cual permite:
-insertar terminos GO con su codigo, funcion biologica y score
- buscar terminos GO por codigo
- generar y visualizar un grafo del arbol usando Graphviz, mostrando:
        - nombre de la funcion biologica
        - score
        - factor de equilibrio FE de cada nodo

#compilar codigo
    g++ -o arbolGo arbolGO.cpp
